# 后台响应式调整与验收记录

日期：2026-09-28。基线：`c8bcbfd`。参照：`https://453400.80909.cn`。

## 实施范围

本轮调整全部 17 个 Lucky5 业务后台页面的共同布局、图标、标题、表单、列表、分页和弹窗。`AGENTS.md` 同步改为按参照保留手机表格；没有修改后端、租户/老板隔离、资金、盘口、退码或结算逻辑。

- 后台主题限定在 `body.lucky-admin-theme`，补齐浅色变量，避免既有暗色缓存污染背景、输入、菜单和弹窗。
- 手机两层 50px 头部、230px 推移菜单、正常页面纵向滚动；主断点为 767/768px。
- 新增 `LegacyTable`：复用现有 Element 列定义、插槽和操作函数，手机使用语义 `thead/tbody/tfoot`，桌面继续使用 Element 表格。
- 普通列表自然换行，会员表格仅内部横向滚动；表尾与表头同列且对齐。
- 表单标签上置、34px 控件、输入左对齐，保存靠右；取消左、确定右，弹窗左右及上方各 10px。
- 采用离线 FontAwesome 4 / Ionicons 2 对应图形，避免菜单和统计卡片依赖在线图标加载。
- 开奖页额外的期号筛选保留，手机收进搜索图标弹出框，不再把整张表格向下挤。
- Nginx 入口文档增加不缓存策略，避免原地部署后旧 HTML 引用已失效的脚本。
